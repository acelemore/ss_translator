# 已放弃

**本项目已放弃，不再维护。**

这是远行星号（Starsector）的集成翻译工具：从 CSV、JSON、jar 抽取文本，交给大模型翻译，再做审核与汉化打包。老式的手搓工作流已被现代的 agent harness 完全替代，这里不会再修 bug、跟版本，也不再接受新需求。

请改用现成的 skill：

**[starsector_chinese_localization_skill](https://github.com/acelemore/starsector_chinese_localization_skill)**

仓库里的代码只作参考。需要时可以把本项目丢给自己的 harness 当材料，不要再按原来的安装步骤跑起来用。

更早的功能说明还留在 [doc/README.md](doc/README.md)，仅供查阅。
